# Tidy Stage 1 — Pipeline + Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Get a skeleton Tidy app building on GitHub's cloud Macs and installed on the owner's
iPhone through SideStore. The skeleton has a Home screen, a signature countdown, and placeholder
area cards. This proves the no-Mac route end to end.

**Architecture:** Pure logic goes in a local Swift package `TidyCore`, tested with `swift test` on
the macOS runner. The SwiftUI app target `Tidy` is generated by XcodeGen from `project.yml` and
depends on `TidyCore`. A GitHub Actions workflow runs the tests, builds an unsigned
`Payload/Tidy.app` → `Tidy.ipa`, and uploads it.

**Tech Stack:** Swift 6, SwiftUI, iOS 17+, XcodeGen, GitHub Actions `macos-latest`, SideStore.

**Spec:** `docs/superpowers/specs/2026-10-20-tidy-design.md` (sections 2, 3, 8 "Home", 10, 11 stage 1)

## Global Constraints

- Minimum iOS 17; Swift 6 language mode.
- Bundle ID `com.jbman03.tidy`. SideStore may append a suffix, so code never reads or compares the
  bundle ID.
- No network calls, no analytics, no iCloud/CloudKit, no push notifications, no App Groups.
- `.xcodeproj` is generated in CI and never committed.
- The IPA is unsigned (`CODE_SIGNING_ALLOWED=NO`), zipped as `Payload/Tidy.app`.
- The owner's PC is Windows: there is no local Xcode/Swift. CI is the test runner, so each task's
  "run tests" step means push and read the GitHub Actions result (`gh run watch`).
- Renewal warning threshold: under 2 days left.

## Review Focus

1. **No provisioning profile** (simulator build, or an unsigned IPA run any other way): Home shows
   "Signature: unknown" and never crashes. Test: `testMissingProfileIsUnknown` (Task 2).
2. **Corrupt or non-plist profile bytes:** returns `nil`, not a crash. Test:
   `testGarbageDataReturnsNil` (Task 2).
3. **Profile without an `ExpirationDate` key:** `nil` → unknown. Test: `testProfileWithoutExpiration`
   (Task 2).
4. **Exact boundaries:** exactly 2 days left = ok, 1 second under = renewSoon, 0 seconds left =
   expired. Test: `testBoundaries` (Task 2).
5. **Malformed IPA layout:** SideStore rejects an IPA unless it holds `Payload/Tidy.app/Info.plist`
   and the executable. CI step `Verify IPA layout` fails the build otherwise (Task 3).

### Task 2: Signature status logic

**Files:**
- Create: `TidyCore/Sources/TidyCore/Signature.swift`
- Test: `TidyCore/Tests/TidyCoreTests/SignatureTests.swift`

**Interfaces:**
- Produces:
  - `public enum ProvisioningProfile { public static func expirationDate(from data: Data) -> Date? }`
  - `public enum SignatureStatus: Equatable, Sendable { case ok(daysLeft: Int), renewSoon(daysLeft: Int), expired, unknown }`
  - `public static func SignatureStatus.evaluate(expiration: Date?, now: Date) -> SignatureStatus`
  - `public var SignatureStatus.message: String`

**Rules:**
- `expirationDate` finds the byte range from `<?xml` through `</plist>` inside the CMS-wrapped
  `embedded.mobileprovision`, parses it with `PropertyListSerialization`, and returns the
  `ExpirationDate` value. It returns `nil` if any part is missing or invalid.
- `evaluate`: `secondsLeft = expiration - now`.
  - `nil` → `.unknown`
  - `secondsLeft <= 0` → `.expired`
  - `secondsLeft < 2*86400` → `.renewSoon(daysLeft: Int(secondsLeft / 86400))`
  - otherwise `.ok(daysLeft: Int(secondsLeft / 86400))`
- `message` copy (exact):
  - ok → `"Signature renews in \(n) days"`, or `"Signature renews in 1 day"` when n == 1
  - renewSoon → `"Signature expires soon — open SideStore to refresh"`
  - expired → `"Signature expired — open SideStore to refresh"`
  - unknown → `"Signature: unknown"`

- [ ] **Step 1: Write the failing tests**

```swift
final class SignatureTests: XCTestCase {
    let now = Date(timeIntervalSince1970: 1_800_000_000)
    func wrap(_ plist: String) -> Data {   // simulate CMS junk around the plist
        Data([0x30, 0x80, 0x06]) + Data(plist.utf8) + Data([0x00, 0xA0])
    }
    func testParsesExpiration() {
        let p = #"<?xml version="1.0" encoding="UTF-8"?><plist version="1.0"><dict><key>ExpirationDate</key><date>2027-01-01T00:00:00Z</date></dict></plist>"#
        XCTAssertEqual(ProvisioningProfile.expirationDate(from: wrap(p)),
                       ISO8601DateFormatter().date(from: "2027-01-01T00:00:00Z"))
    }
    func testGarbageDataReturnsNil() {
        XCTAssertNil(ProvisioningProfile.expirationDate(from: Data([1, 2, 3])))
        XCTAssertNil(ProvisioningProfile.expirationDate(from: Data("<?xml no end".utf8)))
    }
    func testProfileWithoutExpiration() {
        let p = #"<?xml version="1.0"?><plist version="1.0"><dict><key>Name</key><string>x</string></dict></plist>"#
        XCTAssertNil(ProvisioningProfile.expirationDate(from: wrap(p)))
    }
    func testMissingProfileIsUnknown() {
        XCTAssertEqual(SignatureStatus.evaluate(expiration: nil, now: now), .unknown)
        XCTAssertEqual(SignatureStatus.unknown.message, "Signature: unknown")
    }
    func testBoundaries() {
        let d = 86400.0
        XCTAssertEqual(SignatureStatus.evaluate(expiration: now + 2*d, now: now), .ok(daysLeft: 2))
        XCTAssertEqual(SignatureStatus.evaluate(expiration: now + 2*d - 1, now: now), .renewSoon(daysLeft: 1))
        XCTAssertEqual(SignatureStatus.evaluate(expiration: now, now: now), .expired)
        XCTAssertEqual(SignatureStatus.evaluate(expiration: now + 6.5*d, now: now), .ok(daysLeft: 6))
    }
    func testMessages() {
        XCTAssertEqual(SignatureStatus.ok(daysLeft: 6).message, "Signature renews in 6 days")
        XCTAssertEqual(SignatureStatus.ok(daysLeft: 1).message, "Signature renews in 1 day")
        XCTAssertEqual(SignatureStatus.expired.message, "Signature expired — open SideStore to refresh")
    }
}
```

### Task 3: App target, XcodeGen, and CI producing the IPA

**Files:**
- Create: `project.yml`
  - project `Tidy`
  - `options.deploymentTarget.iOS: "17.0"`
  - local package `TidyCore: {path: TidyCore}`
  - target `Tidy` with: type application, platform iOS, sources `App`, dependency on package
    product `TidyCore`
  - settings: `PRODUCT_BUNDLE_IDENTIFIER: com.jbman03.tidy`, `SWIFT_VERSION: 6.0`,
    `MARKETING_VERSION: 0.1.0`, `CURRENT_PROJECT_VERSION: 1`, `INFOPLIST_KEY_CFBundleDisplayName: Tidy`,
    `GENERATE_INFOPLIST_FILE: YES`, `TARGETED_DEVICE_FAMILY: 1`,
    `INFOPLIST_KEY_UILaunchScreen_Generation: YES`
- Create: `App/TidyApp.swift`: an `@main` App showing `HomeView()`
- Create: `App/SigningInfo.swift`:
  `enum SigningInfo { static func current(now: Date = .now) -> SignatureStatus }`. It reads
  `Bundle.main.url(forResource: "embedded", withExtension: "mobileprovision")`, then calls
  `ProvisioningProfile.expirationDate` and `SignatureStatus.evaluate`.
- Create: `App/HomeView.swift`
  - header: "You could free" with "—" (scans arrive in stage 2)
  - one row per `CleanupArea`: icon, title, and a secondary line `"Coming in stage \(stage)"`
  - footer: the signature message, red for `.renewSoon`/`.expired`, secondary otherwise
  - `Text` only, no navigation yet
- Create: `.github/workflows/build.yml`

**Workflow** (on push to `main`, on tags `v*`, and `workflow_dispatch`):
1. `actions/checkout@v4`
2. `swift test --package-path TidyCore`
3. `brew install xcodegen && xcodegen generate`
4. `xcodebuild -project Tidy.xcodeproj -scheme Tidy -configuration Release -sdk iphoneos -derivedDataPath build CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO build`
5. Package: `mkdir Payload && cp -R build/Build/Products/Release-iphoneos/Tidy.app Payload/ && zip -qry Tidy.ipa Payload`
6. **Verify IPA layout:** `unzip -l Tidy.ipa | grep -q 'Payload/Tidy.app/Info.plist' && unzip -l Tidy.ipa | grep -q 'Payload/Tidy.app/Tidy$'`
7. `actions/upload-artifact@v4` with name `Tidy-ipa`, path `Tidy.ipa`
8. On tags only: `softprops/action-gh-release@v2` attaching `Tidy.ipa`
