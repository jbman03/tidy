# Tidy

Tidy is a personal iPhone cleanup app: it finds old screenshots, big videos, duplicate and blurry
photos, duplicate contacts and large files, and lets you swipe through them to keep or delete.
Nothing is deleted without your OK, and everything runs on the phone. It is built on GitHub
Actions (no Mac needed) and installed with SideStore.
